# 1. CORE MISSION DIRECTIVE
Build a high-performance, resilient, and localized web application that empowers farmers, agricultural advisors, and farm managers to diagnose crop diseases, analyze soil health, receive tailored crop cycle schedules, and monitor local weather risks using multimodal generative AI powered by the official `@google/genai` SDK.

# 2. PRODUCT GOAL
Modern agriculture faces escalating risks from climate unpredictability, soil degradation, and pest outbreaks. Smallholder and commercial farmers often lack real-time access to specialized agronomists. 

**AgriVision AI** solves this by delivering an instant, field-tested crop advisory system. Users can upload high-resolution crop leaves/photos, input soil nutrient parameters (pH, N-P-K), set local climate conditions, and generate actionable, localized agronomic advice—including organic and synthetic treatment plans, step-by-step irrigation schedules, and predictive risk alerts.

# 3. MANDATORY FEATURES
1. **Multimodal Visual Crop Diagnosis:** Upload crop images (leaf spots, stem damage, pest sightings) to receive instant disease identification, severity scoring, and immediate mitigation steps.
2. **Soil Health & Fertilizer Calculator:** Input N-P-K values, pH, organic matter percentage, and target crop to receive precise bio-fertilizer and chemical soil amendment plans.
3. **Interactive Crop Advisory & Task Calendar:** Generate localized 90–180 day crop cycle action plans with weekly task breakdowns (sowing, pruning, fertigation, harvesting).
4. **Real-Time Weather Risk & Pest Forecast Engine:** Combine real-time atmospheric data (temperature, humidity, rainfall) with generative pest prediction models to warn of fungal or insect infestation threats.
5. **Multi-Language Agronomist Audio/Visual Output:** Native rendering of advisory outputs with multi-language toggle (English, Hindi, Spanish, Swahili, French) and browser text-to-speech support for low-literacy field access.
6. **Farm History & Historical Field Logs:** Save and review historical diagnoses, field health progression, and previous soil tests per field/plot.

# 6. USER FLOW
1. **Onboarding / Farm Setup:** User opens application, selects farm unit (Acres/Hectares), region, and primary crops grown.
2. **Field Diagnosis Flow:**
   - User navigates to `/diagnosis`.
   - Uploads photo of diseased plant leaf or stems via file picker or live mobile camera.
   - Selects additional contextual observations (e.g., "wilting leaves", "yellow veins").
   - System sends image payload + context to backend Express server.
   - Backend calls Gemini 2.5 Flash via `@google/genai` using structured JSON Schema outputs.
   - Visual diagnostic report displays: Disease Name, Confidence Score, Scientific Name, Immediate Action Items, Chemical & Biological Treatments, Prevention Protocol.
3. **Soil & Crop Cycle Planning Flow:**
   - User navigates to `/soil-analysis`, inputs latest soil lab metrics or target yield goals.
   - AI evaluates nutrient deficits and outputs exact kg/hectare recommendations for Urea, DAP, MOP, or organic alternatives.
   - User can click "Generate Seasonal Calendar" to seamlessly push parameters into `/advisory-calendar`.
4. **Historical Logging:**
   - All analyses auto-persist to PostgreSQL with unique Plot IDs, allowing users to track crop recovery over 30-60-90 day windows.

# 9. DATABASE SCHEMA (PRODUCTION SQL FOR POSTGRESQL)

```sql
-- Enable UUID extension
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- Users / Farmers Table
CREATE TABLE IF NOT EXISTS farmers (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    full_name VARCHAR(255) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    phone_number VARCHAR(50),
    preferred_language VARCHAR(10) DEFAULT 'en',
    farm_location_name VARCHAR(255),
    latitude NUMERIC(10, 7),
    longitude NUMERIC(10, 7),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Field Plots Table
CREATE TABLE IF NOT EXISTS field_plots (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    farmer_id UUID NOT NULL REFERENCES farmers(id) ON DELETE CASCADE,
    plot_name VARCHAR(255) NOT NULL,
    area_hectares NUMERIC(8, 2) NOT NULL,
    soil_type VARCHAR(100) NOT NULL,
    current_crop VARCHAR(100),
    planting_date DATE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Crop Diagnostic Records
CREATE TABLE IF NOT EXISTS crop_diagnoses (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    plot_id UUID REFERENCES field_plots(id) ON DELETE SET NULL,
    farmer_id UUID NOT NULL REFERENCES farmers(id) ON DELETE CASCADE,
    image_url TEXT NOT NULL,
    crop_name VARCHAR(100) NOT NULL,
    disease_identified VARCHAR(255) NOT NULL,
    scientific_name VARCHAR(255),
    confidence_score NUMERIC(5, 2) NOT NULL,
    severity_level VARCHAR(50) NOT NULL, -- Low, Moderate, Severe, Critical
    symptoms JSONB NOT NULL,
    organic_treatment JSONB NOT NULL,
    chemical_treatment JSONB NOT NULL,
    prevention_measures JSONB NOT NULL,
    raw_ai_response JSONB NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Soil Test Records
CREATE TABLE IF NOT EXISTS soil_tests (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    plot_id UUID REFERENCES field_plots(id) ON DELETE CASCADE,
    ph_level NUMERIC(4, 2) NOT NULL,
    nitrogen_ppm NUMERIC(6, 2) NOT NULL,
    phosphorus_ppm NUMERIC(6, 2) NOT NULL,
    potassium_ppm NUMERIC(6, 2) NOT NULL,
    organic_matter_pct NUMERIC(4, 2),
    ai_recommendations JSONB NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Seasonal Advisory Schedules
CREATE TABLE IF NOT EXISTS advisory_schedules (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    plot_id UUID REFERENCES field_plots(id) ON DELETE CASCADE,
    crop_type VARCHAR(100) NOT NULL,
    start_date DATE NOT NULL,
    expected_harvest_date DATE NOT NULL,
    schedule_timeline JSONB NOT NULL, -- Weekly task breakdown
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);
