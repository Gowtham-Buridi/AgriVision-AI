10. ROW LEVEL SECURITY (RLS) / DATA ISOLATION RULES
Execute RLS policies in PostgreSQL to ensure strict multi-tenant isolation per farmer_id.

Farmers can ONLY SELECT, INSERT, UPDATE, or DELETE records where farmer_id = auth.uid() or matching session token context.

Public/Unauthenticated users are prohibited from reading field diagnostic records or soil reports.

11. BACKEND API ROUTES
POST /api/diagnosis/analyze — Accepts multipart image + JSON metadata (cropName, observedSymptoms, language). Executes Gemini 2.5 Flash multimodal inspection. Returns validated diagnosis schema. Saves to DB.

POST /api/soil/recommend — Accepts soil metrics (pH, N, P, K, crop target). Generates structured soil correction & fertilizer regimen.

POST /api/advisory/schedule — Accepts crop type, planting date, and region. Generates weekly agricultural task timeline.

GET /api/plots — Retrieves all field plots for the logged-in farmer.

POST /api/plots — Creates a new field plot record.

GET /api/history/diagnoses — Retrieves paginated historical crop diagnoses.

GET /api/weather/risk — Fetches current regional weather risk indicators and generates AI-driven pest risk forecasts.
